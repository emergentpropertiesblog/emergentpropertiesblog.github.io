{% comment %} Turns speaker prefixes in a roundtable transcript into styled speaker names. A paragraph starting with an author's initials ("RG: ...", "**RG:** ..." or "**RG**: ...") gets that author's short name, linked to their bio. Initials come from `initials` in _data/authors.yml. `include.leader` (a name or initials, from `discussion_leader` in the post's front matter) marks the discussion leader, whose name is highlighted. Paragraphs without a prefix continue the previous speaker's turn and get `rt-cont`, so they line up with the turn's text. A heading, horizontal rule or block quote (e.g. a hypothetical) ends the turn, so it and anything after it without initials stay at the normal left margin. {% endcomment %} {% assign rt_content = include.content %} {% for author_entry in site.data.authors %} {% assign author = author_entry[1] %} {% if author.initials %} {% assign first_name = author.name | split: " " | first %} {% assign display_name = author.short_name | default: first_name %} {% if include.leader == author.name or include.leader == author.initials %} {% assign speaker_class = "rt-speaker rt-leader" %} {% else %} {% assign speaker_class = "rt-speaker" %} {% endif %} {% capture chip %}
